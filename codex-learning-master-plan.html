12-Week Plan

Weeks 1-2: Foundations

  • Learn Codex thread hygiene, AGENTS.md, sandboxing, and approval flow.
  • Practice PowerShell file search, git status, and small edits.

Weeks 3-4: Python Workflows

  • Build scripts with arguments, logging, config files, and tests.
  • Ask Codex to explain diffs and failure messages.

Weeks 5-8: DBA Automation

  • Create Oracle and PostgreSQL inventory, health check, and report scripts.

Weeks 9-12: Delivery

  • Package reusable scripts and document operating procedures.

Prompt Templates

Code Change

Debugging

Error: __. What I tried: __. Expected result: __. Please inspect the code, find root cause, fix it, and verify.

DB Script

Create a Python script for __. Use oracledb thin mode or psycopg2. Do not include real credentials, hostnames, or customer data.

Review

Review this change for bugs, regressions, missing tests, security risks, and unclear behavior. Put findings first.
