Git Commands You Use Most

Check status

git status

See what changed

git diff

Add, commit, and push

git add .
git commit -m "Update study dashboard pages"
git push origin main

Pull latest version from GitHub

git pull origin main

Check remote GitHub link

git remote -v
5

Git Recovery Commands

Use these when Codex or manual editing changed something wrongly.

Undo one file

git checkout -- history/chapter5.html

Undo all uncommitted changes

git checkout -- .

Undo last commit but keep files changed

git reset --soft HEAD~1

Undo last commit and discard changes

git reset --hard HEAD~1

View commit history

git log --oneline
